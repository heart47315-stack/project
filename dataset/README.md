# MEDSAFE AI - Dataset Structure

## จุดประสงค์ของ Dataset

Dataset นี้จัดเตรียมสำหรับเก็บข้อมูลทางการแพทย์และสาธารณสุขสำหรับโปรเจกต์ MEDSAFE AI ประกอบด้วยข้อมูลยา โรงพยาบาลและคลินิก และแหล่งที่มาของข้อมูล

## โครงสร้างไฟล์ CSV

### 1. drugs.csv - ข้อมูลยา
เก็บข้อมูลยาและสารเคมีทางการแพทย์

| คอลัมน์ | คำอธิบาย |
|--------|---------|
| drug_name | ชื่อยา (ภาษาไทย) |
| drug_type | ประเภทของยา (เช่น ยาลดไข้ปวด ยาแก้อักเสบ) |
| dosage_form | รูปแบบยา (เม็ด แคปซูล ครีม เหลว ฯลฯ) |
| active_ingredient | สารประกอบที่ใช้งาน (ชื่อทั่วไป หรือ Generic name) |
| indication | อาการ/โรค ที่ใช้รักษา |
| description | คำอธิบายประเมินความ |
| restriction | ข้อห้ามการใช้ (Contraindications) |
| precautions | ข้อควรระวังเมื่อใช้ |
| source | แหล่งที่มาของข้อมูล |

### 2. hospitals.csv - ข้อมูลโรงพยาบาลและคลินิก
เก็บข้อมูลสถานพยาบาลต่างๆ

| คอลัมน์ | คำอธิบาย |
|--------|---------|
| name | ชื่อโรงพยาบาล/คลินิก |
| type | ประเภท (โรงพยาบาล คลินิก โรงพยาบาลส่วนท้องถิ่น) |
| address | ที่อยู่รายละเอียด |
| province | จังหวัด |
| district | อำเภอ/เขต |
| latitude | พิกัดละติจูด (สำหรับแผนที่) |
| longitude | พิกัดลองจิจูด (สำหรับแผนที่) |
| phone | เบอร์โทรศัพท์ติดต่อ |
| source | แหล่งที่มาของข้อมูล |

### 3. sources.csv - แหล่งที่มาของข้อมูล
เก็บข้อมูลเกี่ยวกับแหล่งข้อมูลทั้งหมด เพื่อความโปร่งใสและการอ้างอิง

| คอลัมน์ | คำอธิบาย |
|--------|---------|
| source_name | ชื่อแหล่งข้อมูล |
| organization | องค์การ/สถาบัน ผู้จัดเตรียมข้อมูล |
| url | ลิงก์ไปยังแหล่งข้อมูล |
| dataset_name | ชื่อชุดข้อมูล |
| description | คำอธิบายเกี่ยวกับข้อมูล |
| last_updated | วันที่อัปเดตล่าสุด |

## วิธีการนำข้อมูลจาก data.go.th

### ขั้นตอนการสกัดข้อมูล:

1. **เข้าเว็บไซต์ data.go.th** (https://data.go.th)
2. **ค้นหา Dataset ที่เกี่ยวข้อง**:
   - สำหรับยา: ค้นหาจาก Ministry of Public Health (สาธารณสุข) หรือ FDA Thailand
   - สำหรับโรงพยาบาล: ค้นหา Hospital Register หรือ Health Facility Database
3. **ตรวจสอบลิขสิทธิ์และข้อกำหนด**: โปรดอ่านข้อตกลงการใช้งาน (License)
4. **ดาวน์โหลด**: เลือกรูปแบบ CSV หรือ JSON
5. **นำเข้าและเปลี่ยนแปลง**: จัดเตรียมข้อมูลให้ตรงกับโครงสร้างของไฟล์นี้
6. **อัปเดต sources.csv**: เพิ่มแหล่งข้อมูลใหม่ลงในไฟล์นี้

### ตัวอย่างแหล่งข้อมูลที่ใช้ได้:
- **ยา**: https://www.fda.moph.go.th (ฝ่ายคุณภาพ สมส.)
- **โรงพยาบาล**: https://thaihealthonline.moph.go.th
- **ข้อมูลสาธารณสุข**: https://data.go.th (ค้นหา health-related datasets)

## ข้อควรระวังเรื่องลิขสิทธิ์และความถูกต้องของข้อมูล

### ⚠️ ลิขสิทธิ์ (Copyright)
- ตรวจสอบใบอนุญาตของแต่ละ Dataset (Open License หรือ Restricted)
- บ่งชี้แหล่งที่มาของข้อมูลอย่างชัดเจน
- ห้ามเปลี่ยนแปลงข้อมูลโดยไม่ได้รับอนุญาต (เว้นแต่เป็นการปรับปรุงความถูกต้อง)
- เขียน Attribution ตามที่ต้องการของเจ้าของข้อมูล

### ⚠️ ความถูกต้องของข้อมูล
- **ตรวจสอบวันที่**: ตรวจสอบว่าข้อมูลไม่ล้าสมัย ยาหรือโรงพยาบาลที่ปิดแล้ว
- **การเชื่อมโยง**: ตรวจสอบว่า Drug Interactions ถูกต้อง
- **พิกัดภูมิศาสตร์**: ตรวจสอบว่า Latitude/Longitude ถูกต้องและแม่นยำ
- **ข้อมูลทางการแพทย์**: ข้อมูลเกี่ยวกับยา คำเตือน อาการข้างเคียง ต้องอ้างอิงจากแหล่งศักยศรัทธา

### ⚠️ การใช้งาน SAMPLE Data
- ข้อมูลที่มีชื่อ "SAMPLE" เป็นตัวอย่างเท่านั้น ห้ามใช้ในงานแพทย์จริง
- ห้ามอ้างว่าข้อมูล SAMPLE เป็นข้อมูลทางการแพทย์ที่เป็นทางการ
- หลังจากเพิ่มข้อมูลจริงแล้ว ให้ลบข้อมูล SAMPLE ออก

## แนวทางการพัฒนา

1. **เพิ่มข้อมูล**: เพิ่มเมื่อได้รับการอนุมัติจากหน่วยงานที่เกี่ยวข้อง
2. **ตรวจสอบคุณภาพ**: ใช้ script validation เพื่อตรวจสอบการเข้ารหัส UTF-8 และความสมบูรณ์
3. **เก็บเวอร์ชัน**: เก็บบันทึกของการเปลี่ยนแปลงและวันที่อัปเดต
4. **แยกข้อมูล Production/Test**: ใช้โฟลเดอร์แยกเพื่อข้อมูล Test และ Production

## Encoding

- ทั้งหมด **UTF-8 with BOM** (recommended สำหรับ Windows) หรือ **UTF-8 without BOM**
- ตรวจสอบด้วยคำสั่ง: `file -i *.csv` (Linux/Mac) หรือ `Get-Content -Encoding UTF8` (PowerShell)
